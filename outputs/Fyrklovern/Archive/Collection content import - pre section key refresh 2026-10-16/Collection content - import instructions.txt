FYRKLOVERN COLLECTION CONTENT IMPORT

1. Create Shopify collection metafield definitions for every key/type in Collection content - mapping and QA report.json.
2. If Collection images - Matrixify Files import.xlsx exists, import its Files sheet first and confirm success.
3. Import Collection content - Matrixify update.xlsx and, if present, Collection metafields only - Matrixify update.xlsx (Collections sheets). Both contain UPDATE rows; metafields are row-based to avoid clearing omitted fields.
4. Import the Collection translations - <language>.xlsx workbooks for enabled Shopify languages.

No Shopify API calls or imports are performed by this script.
